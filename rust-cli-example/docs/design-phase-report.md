### System Design
- **Streaming Processing**: For files >10MB to control memory usage
- **Modular Architecture**: Clean separation of CLI, processing, and output
- **Error Recovery**: Graceful degradation with clear user feedback
- **Cross-platform**: Native performance on all major platforms
