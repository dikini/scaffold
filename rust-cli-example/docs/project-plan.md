# Project Planning Documentation

This directory contains generated documentation from the product planning process.

## 📋 Document Types

### Product Requirements
- `prd/` - Product Requirements Documents and business specifications
- Market research and competitive analysis
- User personas and use cases

### Technical Specifications  
- `technical/` - Technical design documents and architecture
- API specifications and contracts
- Database schemas and data models

### Planning & Timeline
- `roadmap/` - Project timelines and milestone tracking
- Release plans and dependency maps
- Resource allocation and team assignments

### Generated Documentation
Documents are automatically generated by opencode skills:

1. **PRD Documents** - From `skill write-prd`
2. **Analysis Reports** - From `skill analyze-prd`  
3. **Feature Backlog** - From `skill feature-mapping`
4. **Technical Specs** - From `skill tech-design-doc`
5. **Roadmap Visuals** - From `skill project-roadmap`
6. **API Contracts** - From `skill api-contract`

## 🔄 Document Maintenance

- Keep documents updated as requirements evolve
- Use version control for tracking changes
- Regular review with stakeholders
- Align technical specs with PRD updates
