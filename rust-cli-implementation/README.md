# rust-cli-example

A command-line tool for processing text files with various transformations. This tool provides developers and power users with efficient text processing capabilities directly from the command line.

## Getting Started

### Prerequisites

- Rust 1.70+ (install via [rustup](https://rustup.rs/))

### Building

```bash
cargo build
```

### Running

```bash
cargo run
```

### Testing

```bash
cargo test
```

### Linting

```bash
cargo clippy
cargo fmt --check
```
